# Paperclip 介绍

## 什么是 Paperclip？

Paperclip 是一个开源的 AI 智能体编排平台，它将你的 AI 运营建模为一个公司。你不再需要管理一堆零散的脚本和终端窗口，而是定义一个包含角色、汇报线、预算和治理策略的组织架构，然后让智能体在该结构内自主工作。

由 @dotta 创建并于 2026 年 3 月发布，Paperclip 在三周内就突破了 30,000 个 GitHub Stars，成为当年增长最快的开源智能体项目之一。

## 核心理念

### 智能体即公司
大多数多智能体框架要求你把智能体看作流水线：图中的节点、队列中的工作者。Paperclip 采取了不同的视角：你的智能体就是一个公司。有接收目标并进行委派的 CEO 智能体，有执行任务的工程师智能体，还有审查输出的 QA 智能体。协调通过项目和 Issue 进行，就像一个真实的开发团队。

### 默认治理
每个智能体都有角色、预算和上级。行为受治理策略约束。开箱即得审计追踪、成本追踪和状态恢复。

### 心跳执行
智能体不是持续运行的进程。它们按计划唤醒、检查工作、执行动作并汇报。委派沿着组织架构上下流动。这使得成本可预测、行为可观察。

## 核心功能

### 组织架构
- **组织架构图：** 定义汇报结构和权限级别。
- **基于角色的智能体：** CEO、CTO、工程师、QA、研究员——每个都有明确的职责。
- **目标对齐：** 每个任务都能追溯到公司使命。智能体不仅知道做什么，还知道为什么做。

### 预算与成本控制
- **按智能体预算：** 为每个智能体或团队设置月度支出上限。
- **自动限流：** 达到预算上限时智能体自动停止。不会失控消耗 token。
- **成本分析：** 追踪整个组织的 API 成本。

### 多智能体协调
- **智能体间通信：** 智能体之间的结构化消息传递。
- **管理者智能体：** 审查和批准子智能体工作的监督智能体。
- **共享上下文：** 智能体了解其他智能体在做什么，避免重复工作。

### 广泛的智能体后端支持
- **支持的运行时：** OpenClaw、Claude Code、Codex 和自定义智能体。
- **可扩展架构：** 可接入自己的智能体实现。

## 快速开始

### 自托管安装

```bash
git clone https://github.com/paperclipai/paperclip.git
cd paperclip
docker compose up -d
```

### 基本用法

1. **访问仪表板：** 在浏览器中打开 Web UI。
2. **定义公司：** 创建包含角色和汇报线的组织架构图。
3. **设置预算：** 为每个智能体或团队分配月度预算。
4. **创建目标：** 定义一个高层次的公司目标。
5. **让智能体工作：** CEO 智能体分解目标并委派给子智能体。

## 常见用例

### 自动化软件开发
组建一个包含 CTO 智能体、多个工程师智能体和 QA 智能体的 AI 公司。分配一个产品目标，让它们自主设计、实现、测试和审查代码。

### 研究与分析团队
部署一个研究总监智能体和多个专业研究员智能体。它们分工收集信息、交叉验证发现并编写报告。

### 内容生产流水线
创建一个包含写手智能体、编辑智能体和 SEO 智能体的内容团队。它们协作完成草稿、修改和可发布的内容。

## 与类似工具对比

| 工具 | 定位 | 核心差异 |
|------|------|---------|
| **Paperclip** | AI 智能体作为公司 | 组织架构、预算、治理、心跳执行 |
| **Multica** | AI 智能体作为队友 | 任务分配、进度跟踪、技能复用 |
| **OpenClaw** | 单个自主智能体 | 深度：记忆、规划、多平台消息 |
| **LangGraph** | 智能体工作流图 | 代码级 DAG 编排 |
