# Gemini 3.8 TTS

Gemini 3.8 TTS is Google DeepMind's native multimodal text-to-speech model, released on 2026-09-23.

## What it does

- Trained on the native multimodal capabilities of Gemini 3.8 — not a traditional stitched-together TTS pipeline.
- Supports multi-speaker synthesis, multiple emotions, and native low latency.
- Accessible via the Gemini API; a free playground lets you tune voice, speed, and emotion.

## Live Avatar

Released alongside the TTS model, **Gemini 3.8 Live with Live Avatar** enables real-time interactive virtual avatars.
