# Gemini 3.8 TTS

Gemini 3.8 TTS 是 Google DeepMind 推出的原生多模态语音合成模型，发布于 2026-09-23。

## 主要功能

- 基于 Gemini 3.8 的原生多模态能力训练，而非传统 TTS 拼接方案。
- 支持多说话人合成、多种情感表达和原生低延迟。
- 可通过 Gemini API 调用；官方 playground 可免费调试音色、语速和情感。

## Live Avatar

与 TTS 模型同期发布的 **Gemini 3.8 Live with Live Avatar** 支持实时互动的虚拟数字人。
