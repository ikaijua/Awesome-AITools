# ChatGPT Introduction

## What is ChatGPT?

ChatGPT is OpenAI's AI assistant. It supports natural-language conversations, coding help, writing, analysis, image understanding, voice chat, and web browsing. It is available through a web interface, mobile apps, desktop apps, and an API.

## Core Capabilities

- **Conversational AI**: multi-turn dialogue with context awareness and persistent memory.
- **Coding assistant**: writes, explains, debugs, and refactors code in many languages.
- **Content creation**: drafts emails, documents, marketing copy, and creative writing.
- **Multimodal input**: understands images, audio, and documents in addition to text.
- **Web browsing & tools**: can search the web, run data analysis, and use custom GPTs.
