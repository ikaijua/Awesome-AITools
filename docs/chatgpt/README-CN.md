# ChatGPT 介绍

## ChatGPT 是什么？

ChatGPT 是 OpenAI 推出的 AI 助手，支持自然语言对话、编程辅助、写作、分析、图像理解、语音对话和网络浏览。可通过网页、移动应用、桌面应用和 API 使用。

## 核心能力

- **对话式 AI**：支持多轮对话，具备上下文感知与持久记忆。
- **编程助手**：可编写、解释、调试和重构多种编程语言的代码。
- **内容创作**：起草邮件、文档、营销文案和创意写作。
- **多模态输入**：除文本外，还可理解图像、音频和文档。
- **网络浏览与工具**：可搜索网页、进行数据分析，并使用自定义 GPT。
