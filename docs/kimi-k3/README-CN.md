# Kimi K3 介绍

## Kimi K3 是什么？

Kimi K3 是月之暗面（Moonshot AI）推出的 2.8 万亿参数旗舰开源权重模型。它具备原生视觉理解能力、100 万 token 上下文窗口，并采用 Kimi Delta Attention（KDA）架构。K3 是全球首个 3 万亿参数级开源模型，完整权重已在 Hugging Face 以 Modified MIT 许可发布。

## 核心能力

- **超大规模**：2.8T 总参数，采用混合专家（MoE）架构。
- **超长上下文**：100 万 token 上下文窗口，适用于长文档和代码库分析。
- **原生多模态**：统一架构理解图像、视频和文本。
- **Kimi Delta Attention（KDA）**：提升超长序列处理效率。
- **开源权重**：完整模型权重可供研究与本地部署。
