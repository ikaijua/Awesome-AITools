# Kimi K3 Introduction

## What is Kimi K3?

Kimi K3 is Moonshot AI's 2.8-trillion-parameter flagship open-weight model. It features native visual understanding, a 1-million-token context window, and the Kimi Delta Attention (KDA) architecture. It is the first open-source model in the 3-trillion-parameter class, with full weights released on Hugging Face under a Modified MIT license.

## Core Capabilities

- **Massive scale**: 2.8T total parameters with Mixture-of-Experts architecture.
- **Long context**: 1M-token context window for long-document and codebase analysis.
- **Native multimodality**: understands images, video, and text in a unified architecture.
- **Kimi Delta Attention (KDA)**: improves efficiency on very long sequences.
- **Open weights**: full model weights available for research and local deployment.
