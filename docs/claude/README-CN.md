# Claude 介绍

## Claude 是什么？

Claude 是 Anthropic 推出的 AI 助手，以编程、长上下文推理、安全性和企业场景见长。当前旗舰模型为 Claude Opus 5，并提供 Sonnet 与 Haiku 等变体，以平衡速度与成本。

## 核心能力

- **Cowork 模式**：将聊天机器人变成可拉取数据、生成 Excel 预测模型并执行工作流的代理。
- **长上下文推理**：可处理超长文档和大型代码库。
- **编程能力**：擅长多种语言的代码编写、审查和调试。
- **安全与对齐**：设计上力求有用、无害、诚实。
- **Claude Code 与集成**：提供终端编程智能体、IDE 插件、桌面应用、网页界面和 API。
