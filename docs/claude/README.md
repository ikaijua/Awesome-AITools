# Claude Introduction

## What is Claude?

Claude is Anthropic's AI assistant. It is known for strong performance in coding, long-context reasoning, safety, and enterprise use. The latest flagship model is Claude Opus 5, and Claude also offers Sonnet and Haiku variants for different speed-cost trade-offs.

## Core Capabilities

- **Cowork mode**: turns the chatbot into an agent that can pull data, build Excel forecasting models, and execute workflows.
- **Long-context reasoning**: handles very long documents and large codebases.
- **Coding**: strong at writing, reviewing, and debugging code across many languages.
- **Safety & alignment**: designed to be helpful, harmless, and honest.
- **Claude Code & integrations**: available as a terminal coding agent, IDE plugin, desktop app, web interface, and API.
