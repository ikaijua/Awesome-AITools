# 豆包介绍

## 豆包是什么？

豆包是字节跳动推出的 AI 助手，作为字节生态的入口，提供搜索、语音、音乐、图像等多模态交互能力。它面向日常通用问答和任务场景设计。

## 核心能力

- **生态集成**：连接字节跳动旗下服务和内容。
- **多模态交互**：支持文本、语音、图像和音乐。
- **搜索能力**：提供实时信息和答案。
- **日常助手**：适用于通用问答、写作和效率任务。
- **跨平台**：支持网页、移动端和桌面端。
