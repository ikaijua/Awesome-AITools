# Doubao Introduction

## What is Doubao?

Doubao is ByteDance's AI assistant. It serves as an entry point into the ByteDance ecosystem and offers multimodal interactions including search, voice, music, and image capabilities. It is designed for everyday general-purpose questions and tasks.

## Core Capabilities

- **Ecosystem integration**: connects to ByteDance services and content.
- **Multimodal interaction**: supports text, voice, image, and music.
- **Search**: provides real-time information and answers.
- **Daily assistance**: optimized for general Q&A, writing, and productivity tasks.
- **Cross-platform**: available on web, mobile, and desktop.
