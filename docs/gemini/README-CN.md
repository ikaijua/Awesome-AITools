# Gemini 介绍

## Gemini 是什么？

Gemini 是 Google 推出的 AI 助手，原生支持多模态，可在单一模型中处理文本、图像、音频和视频。Gemini 驱动消费级聊天、Deep Research、Google Workspace 功能以及开发者 API。

## 核心能力

- **原生多模态**：理解并生成文本、图像、音频和视频。
- **Deep Research**：规划并执行多步骤网络深度研究。
- **Workspace 集成**：与 Google 文档、表格、幻灯片、云端硬盘和 Gmail 协同工作。
- **编程与推理**：在代码生成、调试和长上下文任务上表现强劲。
- **Gemini Live**：在支持的设备上进行实时语音和视频对话。
