# Gemini Introduction

## What is Gemini?

Gemini is Google's AI assistant. It is built natively multimodal, meaning it can reason across text, images, audio, and video in a single model. Gemini powers consumer chat, Deep Research, Google Workspace features, and a developer API.

## Core Capabilities

- **Native multimodality**: understands and generates text, images, audio, and video.
- **Deep Research**: plans and executes multi-step research across the web.
- **Workspace integration**: works with Google Docs, Sheets, Slides, Drive, and Gmail.
- **Coding & reasoning**: strong at code generation, debugging, and long-context tasks.
- **Gemini Live**: real-time voice and video conversation on supported devices.
