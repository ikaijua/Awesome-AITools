# ARTEMIS

[ARTEMIS](https://github.com/google/artemis) 是 Google 开源的框架，可将自然语言指令转换为可靠的 Android 端自动化工作流，目前已获得 10.5k+ stars。

## 主要功能

- 通过自然语言指令在 Android 上执行跨应用任务。
- 在 AndroidWorld 基准测试（20+ 应用、100+ 多步任务）上任务完成率达 99%+。
- 采用元素索引 + 坐标 + 视觉的多模态目标识别，支持 Compose、Flutter 及 Canvas 自定义界面。

## 执行模式

- **Flash 模式**：3–5 秒/步的快速反应循环，适合确定性任务。
- **Pro 模式**：15–40 秒/步的多智能体图规划与验证，适合长程复杂工作流。

## 工具与集成

- 提供 Web UI 控制台、MCP Server、Python SDK 和 CLI。
- 支持真实设备或模拟器，首次运行会在设备上安装无障碍辅助服务。
- 通过 MCP 与 Antigravity、Codex、Claude Code 等智能体集成。
