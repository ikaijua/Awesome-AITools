# Manus Introduction

## What is Manus?

Manus is an AI action engine developed by Monica. Unlike traditional chatbots that only answer questions, Manus can execute tasks, automate workflows, and extend services on behalf of users. It is designed to operate autonomously in the cloud and deliver finished results.

## Core Capabilities

- **Task execution**: plans and carries out multi-step tasks end-to-end.
- **Workflow automation**: builds and runs repeatable workflows.
- **Cloud agent**: runs asynchronously in the cloud and reports results when ready.
- **Tool use**: can browse the web, write code, analyze data, and interact with documents.
- **Service extension**: integrates with external tools to expand its capabilities.
