# Manus 介绍

## Manus 是什么？

Manus 是由 Monica 团队开发的 AI 行动引擎。与传统只会回答问题的聊天机器人不同，Manus 能够执行任务、自动化工作流程并扩展服务。它设计为在云端自主运行，并向用户交付完整结果。

## 核心能力

- **任务执行**：规划并端到端完成多步骤任务。
- **工作流自动化**：构建并运行可重复的工作流。
- **云端智能体**：在云端异步运行，完成后返回结果。
- **工具使用**：可浏览网页、编写代码、分析数据并与文档交互。
- **服务扩展**：与外部工具集成以扩展能力边界。
