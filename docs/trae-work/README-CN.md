# Trae Work

Trae Work 是字节跳动推出的 AI 工作助手，面向编程与通用办公任务提供 Web、桌面和移动端工作空间。它与 Trae Code（终端编程智能体）和 Trae IDE/SOLO Mode 共同构成 Trae 产品家族。

## 核心特点

- **双模式工作空间**：
  - **Code Mode**：对话优先的编程工作区，支持云端任务流，适合委派构建或编码任务后异步检查结果。
  - **Work Mode**：面向研究、写作、规划、数据分析和文档生产的通用 AI 工作台。
- **云端任务**：支持并发 Cloud tasks，可在后台运行多个长时任务。
- **多端覆盖**：同一账号可在 Web、桌面和移动端继续查看任务进展。
- **IDE 级能力**：与 Trae IDE/SOLO Mode 共享代码库索引、规则、自定义 Agent 和 MCP 扩展能力。
- **成本透明**：基于 token 用量计费，订阅套餐包含基础用量和额外奖励用量。

## 适用场景

- 让 AI 独立完成一个功能实现或重构任务，稍后回来验收结果。
- 跨设备查看和管理进行中的编码/办公任务。
- 使用 AI 辅助完成研究报告、文案、数据分析和项目规划。

## 与 Trae Code / Trae IDE / Trae Solo 的关系

| 产品 | 形态 | 适合场景 |
|------|------|----------|
| Trae Code | 终端 CLI（`trae-cli`） | 喜欢在终端中驱动 Agent 的开发者 |
| Trae IDE – IDE Mode | AI 原生 IDE | 需要直接查看和编辑代码的开发者 |
| Trae IDE – SOLO Mode | IDE 内 Agent 模式 | 本地多文件开发任务 |
| Trae Work – Code Mode | Web/桌面/移动云端编程工作区 | 委派任务、异步验收 |
| Trae Work – Work Mode | Web/桌面/移动通用工作区 | 研究、写作、规划、数据分析 |
