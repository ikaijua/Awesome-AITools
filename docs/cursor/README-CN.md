# Cursor 介绍

## Cursor 是什么？

Cursor 是一款基于 VS Code 构建的 AI 原生代码编辑器。它将大语言模型直接集成到编辑体验中，让开发者可以使用自然语言提示来编写、编辑、调试和理解代码。

## 核心能力

- **AI 代码生成**：根据自然语言描述生成代码。
- **行内编辑**：根据提示重写选中代码或整个文件。
- **代码库理解**：为项目建立索引，跨文件回答代码问题。
- **聊天界面**：就代码、错误和架构进行问答。
- **Agent 模式**：自主规划并执行跨文件编辑和终端命令。
- **VS Code 兼容**：支持大部分 VS Code 扩展、主题和快捷键。
