# Cursor Introduction

## What is Cursor?

Cursor is an AI-first code editor built on top of VS Code. It integrates large language models directly into the editing experience, allowing developers to write, edit, debug, and understand code using natural-language prompts.

## Core Capabilities

- **AI code generation**: generates code from natural-language descriptions.
- **Inline editing**: rewrites selected code or entire files from prompts.
- **Codebase understanding**: indexes the project to answer questions across files.
- **Chat interface**: asks questions about code, errors, and architecture.
- **Agent mode**: autonomously plans and executes multi-file edits and terminal commands.
- **VS Code compatibility**: supports most VS Code extensions, themes, and keybindings.
